# Academic Pulse Design System

## Core Identity
A vibrant, modern, and friendly design system for academic platforms. It balances high-energy brand colors with a structured, professional layout to make registration and course management feel effortless and engaging.

## Color Palette
The palette is centered around a warm "Sunrise" gradient.
- **Primary (#ff4d21):** Used for main actions, high-importance status, and primary branding.
- **Secondary (#ff8c00):** Complements the primary orange to create dynamic gradients.
- **Surface (#f9f9fe):** A very light cool gray to keep the interface feeling airy and clean.
- **Container Surfaces:** Used for cards and grouped content to establish clear hierarchy.

## Typography
Uses **Be Vietnam Pro**, chosen for its excellent readability and modern geometric feel.
- **Headlines:** Large and bold to provide clear entry points.
- **Body:** Optimized for legibility during long tasks like course selection.
- **Labels:** Distinctive and clear for metadata and status tags.

## Components
- **Cards:** Large border radius (16px) with soft shadows to define interactive areas.
- **Navigation:** Clear, persistent navigation bars using consistent icon sets.
- **Status Indicators:** Color-coded badges for 'Success', 'Queuing', and 'Full' states.
- **Buttons:** Bold, vibrant primary buttons with rounded corners and subtle hover transformations.
